# CHANGELOG

## [2.7.0] - (2026.9.7)

### 新增

- 新增视频库统一注册入口 VideoLibraryRegistrar，导出、压缩、保存等入口统一入库
- macOS 剪辑管线迁移到内置 FFmpegKit，无需系统 ffmpeg
- 剪辑器支持点击视频切换播放/暂停，并自动隐藏中央按钮
- 剪辑模式页集成快速试用演示入口
- 修剪时间轴缩略图与压缩/导出视频新增处理类型标记
- 移动端任务列表自动滚动定位到选中的回合/片段

### 优化

- 移动端控件、卡片、导航、权限页与任务页样式全面对齐 restcut
- 外观默认切换为浅色模式 + 石墨色预设
- FFmpeg 导出进度基于 FFmpegKit 统计回调上报真实进度
- CI 在 Windows 平台安装 ffmpeg，导出集成测试全平台可运行
- README 补充功能截图

### 修复

- 修复 macOS Impeller 渲染撕裂（已在 CI 中守卫禁用）
- 修复 Android release 版本 R8 裁剪 onnxruntime 类导致的崩溃
- 修复移动端剪辑进度对话框每次进入任务页重复弹出
- 修复桌面端页面标题与副标题层级显示
- 修复播放器 SetItems 加载状态在控制器就绪前提前消失
- 修复浅色主题下状态栏不可读、首页剪辑图标颜色不统一

## [2.6.0] - (2026.9.5)

### 新增

- 本地检测统一迁移到 ONNX 推理，桌面端支持 CUDA 加速
- 桌面端新增工作区标签页，支持动态侧边栏页面
- 桌面端新增原生启动画面（splash screen）
- 桌面端新增应用内视频播放器，可直接播放任务结果
- 新增可恢复剪辑会话与后台视频导出
- 移动端新增独立的外观设置页面
- 剪辑器与回合片段缩略图跨会话持久化
- 重新设计桌面端快捷键系统，按前台播放 surface 接管播放快捷键

### 优化

- 移动端全站主题化重构（视频、消息、订阅、任务、剪辑、个人页）
- 桌面路由与快捷键作用域统一到 DesktopRoutes 单一来源
- 移动端底部导航与登录遮罩与 restcut_app 对齐
- 登录对话框控件尺寸与表单样式统一
- 修剪时间轴禁用滚轮/触控板滚动，避免误操作

### 修复

- 修复 CI 因子模块指针未推送导致的递归检出失败
- 修复 TpInput 自定义 size/metrics 被 32px 固定轨道覆盖的问题
- 修复桌面工作区标签页关闭/重开的竞态问题
- 修复视频导出进度、通知与会话恢复问题
- 修复 RawVideoRecord 中字符串编码的 videoClipConfigReqVo 解析
- 修复导出视频点击后用系统播放器打开失败的问题
